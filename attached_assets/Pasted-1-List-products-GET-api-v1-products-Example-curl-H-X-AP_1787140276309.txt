1. List products
GET /api/v1/products

Example:

curl \
  -H "X-API-Key: $PRAYAG_API_KEY" \
  "https://prayag-competition-analysis.replit.app/api/v1/products?page=1&pageSize=50&search=pipe"

Supported query parameters:

Parameter	Description
search	Search item code or product name
division	Filter by division
category	Filter by category
page	Page number, starting at 1
pageSize	Number of rows, maximum 200
asOf	Resolve data as of YYYY-MM-DD
Response shape:

3. Get competitor comparison rows
GET /api/v1/comparison

Example:

curl \
  -H "X-API-Key: $PRAYAG_API_KEY" \
  "https://prayag-competition-analysis.replit.app/api/v1/comparison?competitor=Sparsh%20Pearl&page=1&pageSize=50"

Supported query parameters:

Parameter	Description
competitor	Competitor brand
category	Product category
page	Page number
pageSize	Number of rows
Important comparison fields include:

{

JavaScript server-side example
const API_BASE =
  "https://prayag-competition-analysis.replit.app/api/v1";
async function getProducts(search) {
  const url = new URL(`${API_BASE}/products`);
  url.searchParams.set("search", search);
  url.searchParams.set("page", "1");
  url.searchParams.set("pageSize", "50");
  const response = await fetch(url, {
    headers: {
      "X-API-Key": process.env.PRAYAG_API_KEY
    }
  });
  if (!response.ok) {
    throw new Error(`Prayag API failed: ${response.status}`);
  }
  return response.json();
}

Error responses
Missing or invalid keys return:

401 Unauthorized

{
  "error": "Missing API key. Pass it in the X-API-Key header."
}

The internal Price Finder endpoints are different:

/api/price-finder/search
/api/price-finder/browse
/api/price-finder/product/{itemCode}

Those currently require a logged-in browser session and are intended for the first-party Price Finder app. For another application, use the stable /api/v1 endpoints above.
